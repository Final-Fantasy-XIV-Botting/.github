## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository contains reference materials and does not include an executable that attaches to the game.

### Can antivirus software detect this bot?

There is no functional bot executable in this repository. Be cautious with external downloads claiming to automate Final Fantasy XIV, particularly files from unknown sources.

### Is it compatible with Windows 11?

The reference materials can be viewed on Windows 11. They do not provide a functional Windows bot.

### Does it automate gathering, crafting, or farming?

No. The repository explains these gameplay systems and related automation terminology but does not perform automated actions.

### Is botting allowed in Final Fantasy XIV?

No. Square Enix prohibits unauthorized bots, automation software, and tools that enable unattended gameplay. Violations can result in temporary suspension or permanent account termination.
